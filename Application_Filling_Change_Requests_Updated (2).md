# Application Filling - Change Requests

## UI Changes

1.  **Application Reference Number**
    -   The **Application Reference Number** **text box** should be
        displayed only when an **Applicant** is selected from the
        dropdown.
    -   If no applicant is selected, the **Application Reference
        Number** **text box** should remain hidden.
2.  **Save Status**
    -   Remove the **Save Status** field.
3.  **Profile Photo**
    -   Do not display the **Profile Photo** field in the **Personal
        Info** section.
    -   If the Profile Photo is retained, automatically use the same
        photo as the **Student Photo** in the **Documents** section.
4.  **Remove Dropdowns**
    -   Remove the **Enquiry** dropdown.
    -   Remove the **Intake** dropdown.
5.  **Academic Information**
    -   Populate the following fields from **Application Payment**:
        -   Campus
        -   Program
        -   Semester
        -   Fee Structure
        -   Batch
        -   Batch Time
    -   These fields should be displayed as read-only and should not be
        editable by the user.
6.  **Passport Number**
    -   If a **Passport Number** is entered, lock the **Refugee / Asylum
        Seeker Student?** option.
7.  **Family Details**
    -   Remove the **Family Details** tab.
