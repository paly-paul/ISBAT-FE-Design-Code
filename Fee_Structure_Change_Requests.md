# Fee Structure - Change Requests

## Program Fee Structure

1.  **Ledger**
    -   Remove the **Fee Title** field.
    -   Display the **Ledger** dropdown in place of the **Fee Title**
        field.
    -   The **Ledger** dropdown should appear first.
2.  **Ledger Priority**
    -   Add a **Ledger Priority** text box.
3.  **Edit Fee Structure**
    -   When the user selects the **Edit** option, display the
        associated **Programme**.
    -   The **Programme** field should be displayed as read-only and
        should not be editable.
    -   Similarly, display the associated **Intake** as read-only
        without providing an option to edit it.
4.  **Create Fee Structure**
    -   While creating a new fee structure, do not provide an **Intake**
        dropdown.
    -   Display only the **Current Intake** as a read-only field.
    -   Use the existing **Current Intake** filter to retrieve and
        display the current intake.
